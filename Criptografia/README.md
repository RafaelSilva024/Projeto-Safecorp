# Entrega 1 - Criptografia Assimétrica e Confiança

## Interação com o Usuário
Este módulo permite que o usuário digite sua própria mensagem em tempo real para cifragem e decifragem interativa.

## Execução

### Modo Interativo (Digitando a mensagem):
```bash
python main.py
```

### Modo Teste Automático:
```bash
python teste.py
```
